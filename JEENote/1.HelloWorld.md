# 1. HelloWorld

## 目标

通过 IDEA 创建一个 Maven 架构的 Spring Boot 项目，并使用控制器在浏览器输出 `Hello World`。

## 一、在 IDEA 中创建 Spring Boot 项目

1. 打开 IDEA，点击 `New Project`。
2. 选择 `Spring Boot`。
3. `Build system` 选择 `Maven`。
4. `JDK` 选择 `17`。
5. 填写项目信息：

```text
Group: com.yus
Artifact: springboot-demo
Name: springboot-demo
```

6. 在依赖里选择 Web 相关依赖，一般选择：

```text
Spring Web
```

7. 点击 `Create`，等待项目初始化完成。

## 二、项目基本结构

创建完成后，常见目录如下：

```text
src
 ├─ main
 │  ├─ java
 │  │  └─ com.yus
 │  │     └─ SpringbootDemoApplication.java
 │  └─ resources
 │     ├─ static
 │     ├─ templates
 │     └─ application.properties
 └─ test
```

说明：

- `src/main/java`：写 Java 代码。
- `src/main/resources/static`：放静态页面、CSS、JS、图片。
- `SpringbootDemoApplication.java`：Spring Boot 启动类。

## 三、启动类说明

启动类一般如下：

```java
package com.yus;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class SpringbootDemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringbootDemoApplication.class, args);
    }

}
```

这个类的作用是启动项目，一般不在这里写网页标签，也不在这里直接写业务逻辑。

## 四、创建控制器输出 Hello World

在 `src/main/java/com/yus` 目录下新建：

```text
HelloController.java
```

代码如下：

```java
package com.yus;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public String hello() {
        return "Hello World";
    }
}
```

说明：

- `@RestController`：表示当前类是控制器，并且返回的数据直接写到页面上。
- `@GetMapping("/hello")`：表示浏览器访问 `/hello` 时，会执行 `hello()` 方法。
- `return "Hello World";`：把字符串返回给浏览器。

## 五、运行项目

运行方式：

1. 打开 `SpringbootDemoApplication.java`
2. 点击左侧绿色运行按钮
3. 或者右键选择 `Run 'SpringbootDemoApplication'`

启动成功后，控制台通常会看到 Tomcat 启动信息。

## 六、在浏览器查看结果

项目启动后，在浏览器输入：

```text
http://localhost:8080/hello
```

如果配置正常，页面会直接显示：

```text
Hello World
```

## 七、补充说明

### 1. Java 代码写在哪里

Java 控制器应写在：

```text
src/main/java/com/yus
```

不要把控制器写到错误的包路径下，否则 Spring Boot 可能扫描不到。

### 2. HTML 写在哪里

如果以后要写网页页面，可以把 HTML 文件放到：

```text
src/main/resources/static
```

例如：

```text
src/main/resources/static/index.html
```

如果只是练习通过控制器输出字符串，那么先不需要写 HTML 文件。

本节完成了以下内容：

2. 了解了项目的基本目录结构。
3. 创建了 `HelloController` 控制器。
4. 通过 `/hello` 路径在浏览器输出了 `Hello World`。
