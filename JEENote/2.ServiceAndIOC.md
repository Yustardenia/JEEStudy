# 二、Drivable 接口

定义一个 **交通工具接口**：

``` java
public interface Drivable {
    void drive();
}
```

含义：

任何交通工具只要实现 `Drivable`，就必须实现 `drive()` 方法。

------------------------------------------------------------------------

# 三、交通工具实现类

例如：

``` java
@Component("Car")
public class Car implements Drivable{

    @Override
    public void drive() {
        log.info("开着车出去浪~");
    }

}
```

其他实现类：

-   Bike
-   Train
-   Ship
-   AirPlane

它们都实现了 `Drivable` 接口。

这样做的好处是：

**Person 不需要关心具体交通工具类型，只需要依赖 Drivable。**

这就是 **面向接口编程**。

------------------------------------------------------------------------

# 四、Person 实体

``` java
@Component
public class Person {

    private String name;
    private Drivable drivable;

    public void hangOut() {
        drivable.drive();
    }

}
```

说明：

Person 有两个属性：

  属性       含义
  ---------- ----------
  name       人的名字
  drivable   交通工具

`hangOut()` 方法：

    出去玩 -> 使用交通工具

Person **并不创建交通工具对象**。

而是 **由外部提供**。

这就是 **依赖注入（DI）**。

# 五、手写简单 IoC 容器

Container 类：

``` java
public class Container {

    private Map<Class<?>,Object> beans = new HashMap<>();

    public <T> T getBean(Class<T> key) {
        return (T) beans.get(key);
    }

    public <T> void put(Class<T> key, T value) {
        beans.put(key, value);
    }

}
```

容器作用：

  方法        作用
  ----------- ----------------
  put()       向容器放入对象
  getBean()   从容器获取对象

底层原理其实就是：

    Map<Class , Object>

# 六、手动 IoC 测试

测试类：

``` java
IocTests
```

初始化容器：

``` java
container = new Container();

container.put(Bike.class,new Bike());
container.put(Car.class,new Car());
container.put(Train.class,new Train());
container.put(AirPlane.class,new AirPlane());
container.put(Ship.class,new Ship());
```

此时：

    容器中已经存储了多个对象

使用方式：

``` java
Drivable bike = container.getBean(Bike.class);
xiaoming.setDrivable(bike);
xiaoming.hangOut();
```

流程：

    容器 -> 获取对象 -> 注入 Person -> 使用

这样 Person **不需要自己 new 对象**。

# 七、Spring IoC 容器

Spring 已经帮我们实现好了 IoC 容器。

只需要使用注解即可。

## 1 添加组件

``` java
@Component
```

表示：

    把当前类交给 Spring 管理

例如：

    Car
    Bike
    Train
    Person

------------------------------------------------------------------------

## 2 自动注入

``` java
@Autowired
private Car car;
```

表示：

    从 Spring 容器中自动获取对象

Spring 会：

1.  扫描组件
2.  创建对象
3.  注入依赖

# 九、IoC 核心思想

IoC（Inversion of Control）

传统方式：

    对象自己创建依赖

例如：

    Person -> new Car()

IoC方式：

    对象由容器创建
    容器负责注入依赖

    Container -> Person
    Container -> Car

这样代码 **解耦**。
